# apricot.cc

`apricot.cc` is a distinct Minecraft: Bedrock Edition client forked from Borion. This codebase also carries legacy Horion components, which remain attributed and available through compatibility interfaces.

## Contributing

Fork this repository, make your changes, and submit a pull request. The [Horion wiki](https://github.com/horionclient/Horion/wiki) and [contributor guide](https://github.com/horionclient/Horion/contribute) document the inherited code and build setup.
